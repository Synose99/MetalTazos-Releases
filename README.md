# Metal Tazos

## Pobierz grę

**[Przejdź do najnowszego wydania](https://github.com/Synose99/MetalTazos-Releases/releases/latest)**

1. Pobierz plik **MetalTazos-Launcher-…zip** z sekcji Assets.
2. Rozpakuj cały ZIP do folderu i uruchom **MetalTazosLauncher.exe**.
3. Wybierz **Zainstaluj grę**, poczekaj na pobranie i kliknij **Graj**.

Launcher sprawdza aktualizacje po uruchomieniu. Kolejne wydania zainstalujesz przyciskiem **Aktualizuj**. Zachowaj obok EXE plik `launcher.json`. Konto GitHub nie jest potrzebne.

## 

Obie osoby powinny mieć aktualną wersję. W grze wybierzcie **MULTIPLAYER 1V1**, swojego tazosa i **WYSZUKAJ GRACZA**.

## Wymagania i pliki

Windows 10/11 64-bit, .NET Framework 4.8 dla launchera. To prototyp do testów ze znajomymi.

Pełny ZIP `MetalTazos-…zip` pozwala także rozpakować grę ręcznie. `latest.json` jest manifestem aktualizacji. Archiwa **Source code** nie zawierają gry.

Repozytorium udostępnia gotowe wydania i instrukcję pobierania.
